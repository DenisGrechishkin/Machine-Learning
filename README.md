## Лабораторная 1: Основы Keras и персептроны
Архитектура: Полносвязная сеть (1 слой, 1 нейрон) для линейной регрессии.
Задачи:
  - Обучение базовой модели на синтетических данных.
  - Визуализация процесса обучения и предсказаний.
  - Демонстрация переобучения при искусственном увеличении количества нейронов и эпох.
  - Настройка кросс-валидации (validation_split=0.2).
## Лабораторная 2: CNN и семантическая сегментация
Архитектура: U-Net с предобученным бэкбоном MobileNetV2 и skip-connections
Задачи:
  - Построение и обучение базовой U-Net для датасета Oxford-IIIT Pet
  - Доработка модели: добавление Dropout, тонкая настройка (разморозка слоёв бэкбона)
  - Сравнение качества при заморозке/разморозке весов предобученного энкодера
  - Аугментация данных (RandomFlip, сдвиги, масштабирование)

## Лабораторная 3: Рекуррентные сети (LSTM)
Архитектура: LSTM-сети (в т.ч. Bidirectional) с Embedding-слоем.
Задачи:
  - Классификация текстов: Обучение модели на 5 классов английских текстов. Применение BatchNormalization, Early Stopping и оптимизация батчей (сортировка по длине последовательностей).
  - Прогнозирование RUL: Предсказание остаточного ресурса ракетных двигателей (датасет NASA C-MAPSS). Предобработка данных, агрегация последовательностей по ID двигателя, расчёт метрик.
## Лабораторная 4: Сегментация изображений (U-Net)
Архитектура: U-Net с предобученным бэкбоном MobileNetV2 и сквозными соединениями (skip-connections).
Задачи:
  - Построение и обучение базовой U-Net для датасета Oxford-IIIT Pet.
  - Доработка модели: добавление Dropout, тонкая настройка (разморозка слоёв бэкбона), сравнение качества при заморозке/разморозке весов.
  - Подготовка нового датасета для сегментации (пожар / водоём / свалка), ручная разметка масок (VIA).

## Лабораторная 5: Графовые нейронные сети (GNN)
Архитектура: Кастомные графовые слои (MessagePassing, EdgeNetwork, GraphConv), агрегация и комбинация признаков.
Задачи:
  - Классификация вершин: Работа с датасетом цитирований (Cora: 2708 вершин, 1433 признака). Настройка параметров агрегации, комбинации и dropout.
  - Предсказание свойств молекул: Парсинг данных через RDKit, преобразование в графы, обучение GNN на регрессию/классификацию молекулярных свойств.
  - Сравнение времени обучения на CPU и GPU, стабилизация метрик (AUC) относительно базовой модели.
